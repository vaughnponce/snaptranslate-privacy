Privacy Policy for SnapTranslate

SnapTranslate is a Chrome extension that allows users to select any screen area, extract text using OCR, and translate it with AI.

What data we process

  • The text or image content that you select on the screen is temporarily sent to an AI translation API to generate the translation.
  • We do not collect, store, or share any personal information such as your name, email, or browsing history.

Data storage

  • Selected content is processed only for the purpose of translation and is not stored by us after the translation is completed.
  • User preferences (such as language settings) may be saved locally in your browser.

Third-party services

We use an AI translation API to provide the translation feature. The selected text is sent to this service only for translation purposes.

We do not sell or transfer user data to third parties for advertising or other unrelated purposes.
